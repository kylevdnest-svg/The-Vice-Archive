# The Vice Archive

**Creator:** SableInk  
**Stage:** Pre-production — art-pipeline feasibility / commercial concept validation  
**Snapshot:** 2026-11-06 (Africa/Johannesburg)

The Vice Archive is a proposed **small, standalone, commercial adult management game** set in a modern, luxurious, gothic-influenced private fantasy studio housed in a renovated theatre. It is separate from Cities 2077 and HEMOCODE: VESPER.

**Core pitch:** Build a struggling establishment into a respected destination by matching requests to adult performers, configuring staged fantasy experiences, managing resources, and unlocking authored character and adult-content rewards. The distinguishing feature is **fantasy creation / matching**, not the size or complexity of the simulation.

**Commercial guiding principle:** The adult content should be appealing, and the gameplay should make unlocking it worthwhile. Ship a finite, polished game rather than an endless sandbox.

## Current status

- **Confirmed:** Creative/commercial direction, initial scope preferences, visual reference, local art-tool setup, and the basic GPU image-generation pipeline.
- **NOT completed:** A validated production art style, an approved named character, consistent multi-view character assets, an adult-scene production pipeline, a playable prototype, gameplay implementation, a Steam submission or a release date.
